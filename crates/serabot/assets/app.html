Access

This is a private single-operator deployment. The API and both clients require an access token issued by the operator. Downloading a client does not grant access, and no token is embedded in any build.

Verify a build

Published assets are listed in SHA256SUMS. Compare the hash of the downloaded file before installing.

Android: allow installation from unknown sources and sideload the APK. Windows: unzip or run the executable.
