# Design / brand

1. Load owner brand constraints from the deterministic renderer (configured `brand_file`).
2. Prefer clear hierarchy: part dividers, concise card headings, limited bullets.
3. Use monogram chips only when the brand config enables them.
4. Keep decks within configured `max_pages`; split content rather than shrinking text illegibly.
5. Produce Italian first; French only after approved Italian artifact when bilingual.

Pair with the `deck` skill for end-to-end deck workflows.
