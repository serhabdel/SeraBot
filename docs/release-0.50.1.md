# Release 0.50.1

Fixes for the v0.49/v0.50 Providers page.

- **Browser sign-in is reachable.** Saving Antigravity, Muse or OpenRouter no longer fails with "secret ... is empty"; members hold their own sealed tokens. Each provider card has a Sign in / Add account button, per-account Sign in again, and a "Save and sign in" path from the Add provider dialog.
- **Antigravity sign-in works out of the box.** The dead end "Antigravity sign-in is not set up on this server. Ask the owner to store its OAuth client secret" is gone. As in the owner's HielCowork, Google's public installed-application client id and secret are compiled in as defaults (a public credential, not a private secret). Precedence for the secret: one saved in the encrypted store (console Advanced field, optional override), then the `AGY_CLIENT_SECRET` environment variable, then the default. The directory's Sign in button goes straight to Google. Muse Code already carries its public client id and had no such dead end.
- **Claude sign-in and several accounts.** The Anthropic (Claude) card offers both Sign in with Claude (browser PKCE on `localhost:54545`, several accounts) and Add API key (several keys). `plan_oauth` now defaults on (set `plan_oauth = false` to turn it off); it stays admin-only, the page shows the risk banner (it signs in through Claude's own client, Anthropic may restrict it, your own account, never shared), and the client id is Claude Code's public one with an optional age-store override. Endpoints, scopes and headers follow the owner's aio-proxy `claude-code` plugin: HielCowork itself has no raw Claude OAuth (it drives the Claude Code CLI), so aio-proxy is the only source for these details. Chat and refresh requests carry the bearer, `anthropic-beta: oauth-2025-04-20`, `anthropic-version` and the SDK user agent that plugin sends.
- **Model lists** follow the owner's HielCowork tables (2026-11-02) and vendor docs; ids that could not be confirmed were left out. Use Fetch models to refresh from the provider.

Not verified: no live sign-in (Google or Claude) or live model catalog check was run; tests use synthetic fixtures.
